# resume-check

Read `utils/job-search/resume-check/00-principles.md`, then follow `utils/job-search/resume-check/01-check/check.md` with its rubrics (`rubrics/ats-rules.md`, `rubrics/resume-best-practices.md`) and shared material (`shared/labels.md`, `shared/levels.md`, `shared/ai-signals.md`, plus the level files for the confirmed current and target levels).

If the user's spine exists (`my-files/profile.md` + `my-files/story-bank.md` at kit root), load it and run the workflow's Step 7 cross-check, a Strong story the bank holds that the resume never shows is the check's best finding. Never re-ask what the bank answers. Scratch results go to the util's `my-files/`, dated; never commit or transmit them.
