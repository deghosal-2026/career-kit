# cover-letter

Read `utils/job-search/cover-letter/00-principles.md`, then follow `utils/job-search/cover-letter/01-draft/draft.md` with `shared/labels.md` and the spine's extraction rules (`spine/03-use/use.md`).

The spine is required: load `my-files/profile.md` + `my-files/story-bank.md` at kit root first; if it doesn't exist, offer capture. Company facts come only from the JD or the user. The user reviews and edits the draft; the kit never sends anything anywhere. Scratch drafts go to the util's `my-files/`, dated; never commit or transmit them.
