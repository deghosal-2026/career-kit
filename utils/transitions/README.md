# Transitions

Utils for the non-linear parts of a career — the moments generic advice handles worst.

| Util | What it does | Status |
|---|---|---|
| career-gap | Frame a gap honestly from the timeline; options for presenting it, never hiding what would be untrue to omit | planned |
| discipline-switch | Map adjacent evidence across disciplines (SRE → platform, data → software); what reframes honestly, what is a real gap | planned |
| exit-and-return | Leaving a role gracefully (handover, knowledge transfer) and returning after time away | planned |

These stay out of the spine: the spine records what happened; these utils decide how to present it, with the user choosing.
