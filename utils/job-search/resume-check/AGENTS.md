# AGENTS.md, resume-check

Instructions for any AI agent working in this util. Kit governance (`AGENTS.md`, `WHAT-THIS-IS.md`, `CONVENTIONS.md`) comes first; this util's `00-principles.md` overrides the workflow.

## How to run it
1. Read `00-principles.md`, then `01-check/check.md`.
2. Rubrics: `rubrics/ats-rules.md`, `rubrics/resume-best-practices.md`, `rubrics/linkedin-sections.md`.
3. Shared material: `shared/labels.md`, `shared/levels.md`, `shared/ai-signals.md`, and the level files under `shared/` for the confirmed current and target levels, plus the discipline's `README.md`.
4. The spine: if `my-files/profile.md` and `my-files/story-bank.md` exist at kit root, load them before the check and run the workflow's Step 7 cross-check. Never re-ask the user for facts the bank answers. If they don't exist, offer capture after the check.
5. LinkedIn: if the user has downloaded their profile (Save-to-PDF text or the data export) and placed it in this util's `my-files/` or pasted it, run the workflow's Step 8 LinkedIn cross-reference against `rubrics/linkedin-sections.md`. Never invent profile contents; never upload anything.

## Storage
Scratch results go to this util's `my-files/` with a dated name, for example `my-files/2026-11-18-resume-check.md`. Never commit, push, or transmit them.
