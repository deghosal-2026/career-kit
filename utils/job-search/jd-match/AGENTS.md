# AGENTS.md — jd-match

Instructions for any AI agent working in this util. Kit governance (`AGENTS.md`, `WHAT-THIS-IS.md`, `CONVENTIONS.md`) comes first; this util's `00-principles.md` overrides the workflow.

## How to run it
1. Read `00-principles.md`, then `01-match/match.md`.
2. Rubric: `rubrics/match-rubric.md`.
3. Shared material: `shared/labels.md`, `shared/levels.md`, `shared/ai-signals.md` (when a JD mentions AI), and the level files under `shared/` for each JD's implied level.
4. The spine is required: load `my-files/profile.md` and `my-files/story-bank.md` from kit root before matching. If they don't exist, say so and offer the spine's capture workflow — never match against a raw resume, and never re-interview for facts the bank should hold.

## Storage
Scratch results go to this util's `my-files/` with a dated name, for example `my-files/2026-11-18-jd-match-torvale.md`. Never commit, push, or transmit them.
