# Job search

Utils for the paper and the process of finding the next role. All of them draw on the spine (`../../spine/`) — a resume line, a match table, or a letter cites a story, never a memory.

| Util | What it does | Status |
|---|---|---|
| resume-check | Level fit against the shared ladder, ATS named checks, best practices, spine cross-check | **Ready — v0.1 (2026-11-18)** |
| jd-match | JD requirements rated against the spine, with a gap plan | **Ready — v0.1 (2026-11-18)** |
| cover-letter | Evidence-traced letter drafts from the spine and the JD | **Ready — v0.1 (2026-11-18)** |
| linkedin-review | Profile review; public-safe lines extracted from the bank | planned |
| application-tracker | Pipeline over applications, statuses, follow-ups | planned |
| interview-prep | STAR answers from the bank, JD-specific drills, debriefs | planned |
| outreach | Referral asks, recruiter notes, networking drafts | planned |
