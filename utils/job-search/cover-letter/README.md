# Cover letter

Drafts a short, specific cover letter for one job, from the spine and the job description. Every claim points to a story by ID; company facts come only from the JD or from you; gaps are never papered over. It is a draft: you review and edit it. The kit never sends anything anywhere.

Who it is for: ICs and leaders in the disciplines the kit covers, applying to roles a cover letter helps with.

## Files

| Path | What it is |
|---|---|
| `00-principles.md` | this util's constitution |
| `01-draft/draft.md` | the workflow |
| `tests/` | fake personas with expected answer keys |
| `examples/` | pointers to worked-example material |
| `my-files/` | scratch results (git-ignored) |

Also uses: `shared/labels.md`, the spine (`spine/03-use/use.md`), and the JD match (`utils/job-search/jd-match/`) result when you have one. **The spine is required**, if there is no story bank yet, build it first (`spine/START.md`).

## How to use

- **In any AI chat:** paste `START.md` and follow what it asks.
- **With an AI agent that reads files:** say "draft a cover letter for this JD", the agent follows `AGENTS.md`.
