# AGENTS.md — cover-letter

Instructions for any AI agent working in this util. Kit governance (`AGENTS.md`, `WHAT-THIS-IS.md`, `CONVENTIONS.md`) comes first; this util's `00-principles.md` overrides the workflow.

## How to run it
1. Read `00-principles.md`, then `01-draft/draft.md`.
2. Shared material: `shared/labels.md`.
3. The spine is required: load `my-files/profile.md` and `my-files/story-bank.md` from kit root before drafting. If they don't exist, offer the spine's capture workflow — never draft career claims without sourced stories.
4. A JD match result from `utils/job-search/jd-match/` may exist in this util's or the jd-match's `my-files/`; reuse it if the user references it.

## Storage
Drafts go to this util's `my-files/` with a dated name, for example `my-files/2026-11-18-cover-letter-torvale.md`. Never commit, push, or transmit them — and never send a letter anywhere on the user's behalf.
