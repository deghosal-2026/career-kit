# Offers

Utils for the decision end of the process: evaluating what's on the table and negotiating over it.

| Util | What it does | Status |
|---|---|---|
| offer-evaluation | Side-by-side worksheet the user fills: base, equity, role scope, team, growth; trade-offs named, never a score | planned |
| negotiation | Scripts and counter-offer drafts from the user's own facts — no invented leverage, no market-rate claims from scraped data | planned |

Both planned only. Design notes from the research: negotiation tools that estimate salary or draft claims for you (Salary-Negotiation-Skill, reflect) are the anti-pattern; the honest version drafts *questions and structures* and leaves every number to the user.
