# my-files/

Your private material. Git ignores everything here except this file.

The spine data lives here: `my-files/profile.md` and `my-files/story-bank.md`. Every util reads those two files; none of their content is ever committed or sent anywhere. A util's own `my-files/` holds that util's scratch results, also git-ignored.

Results land here with a dated name, for example `my-files/2026-11-18-resume-check.md`.

Remove your phone number and home address before pasting material into a hosted AI tool.
