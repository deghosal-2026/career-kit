# Profile template

Version 0.1 (2026-11-18). The profile half of the spine: one file, every structural fact, each with a status. `01-capture` fills it; every util reads it.

Rules: facts only, the person's own words, no phone number / home address / date of birth / ID numbers, no scores.

| Status | Meaning |
|---|---|
| **From CV** | copied from the material as written |
| **Confirmed** | the person's own answer |
| **Needs confirm** | doubt or gap; see Open questions |
